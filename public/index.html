Game 1: exact best response

Game 1 is additive across castles, so the best allocation against a population is found exactly (knapsack DP plus enumeration of every allocation).

Game 2: optimizer (evolutionary + local search)

Optimizes on one sampled set of groups (common random numbers), then re-validates the top allocations on fresh groups.

Self-play (fictitious play)

Each iteration best-responds to the starting population (weight = anchor) mixed with every earlier best response.

Round robin among your own list

One allocation per line, optionally prefixed by a name and colon, e.g. mine: 0 10 20 30 40. Game 1 is computed exactly over all pairs. With 4 or more entries, Game 2 is computed exactly over every group.
